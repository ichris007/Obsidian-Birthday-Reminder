# Obsidian Birthday Reminder（生日提醒）

[English](https://github.com/ichris007/Obsidian-Birthday-Reminder/blob/main/README.md) | [中文文档](https://github.com/ichris007/Obsidian-Birthday-Reminder/blob/main/README-ZH.md)

## 1 📖 简介

**Birthday Reminder** （生日提醒）是一款为 Obsidian 设计的生日提醒插件，帮助你轻松管理亲朋好友、同事客户的重要生日信息。插件支持公历/农历转换、生肖星座显示、智能日历视图，并自动适配侧边栏和主窗口布局。

无论你是用 Obsidian 管理个人生活，还是作为 CRM 工具管理客户关系，这款插件都能让你的生日提醒变得优雅而高效。

## 2 ✨ 功能特点

### 2.1 🎯 核心功能

|功能|说明|
|---|---|
|**可配置生日属性**|✨ 支持自定义 frontmatter 属性名，兼容 `birthday`、`date_of_birth`、`DOB` 等任意命名|
|**智能生日计算**|自动计算下一个生日日期和剩余天数，准确判断今年生日是否已过|
|**年龄自动计算**|根据出生日期自动计算即将到来的年龄|
|**农历转换**|使用 `solarlunar` 精确转换公历到农历，支持闰月显示|
|**生肖星座**|自动显示生肖和星座信息，增添文化趣味|
|**目录过滤**|可指定扫描特定文件夹，避免扫描整个仓库|
|**农历生日**|✨ 支持按农历记录生日，闰月可写 `2023-02L-01`|
|**每日提醒**|每天一条通知，汇总今天与即将到来的生日|
|**搜索与排序**|按姓名或别名筛选（输入框带一键清空），按剩余天数 / 姓名 / 年龄排序|

### 2.2 📊 数据统计

- **统计卡片**：总人数、今日生日、7天内生日、30天内生日一目了然
- **自动分组**：今日生日、最近一周、最近一个月、更远的生日分类显示
- **可切换排序**：默认按剩余天数，也可按姓名（中文按拼音）或年龄排序；排序在每段内部生效

### 2.3 📅 日历视图

- **月历显示**：以日历形式展示所有生日，生日日期高亮显示
- **月份导航**：支持上月/下月切换，一键返回今天
- **生日预览**：日历格子上直接显示当天过生日的人名
- **点击跳转**：点击任意生日卡片或日历格子，直接跳转到对应笔记

### 2.4 🎨 界面适配

- **响应式布局**：自动检测窗口宽度，侧边栏模式紧凑显示，主窗口模式完整显示
- **多套配色**：5种内置配色方案（默认、温暖橙、清新蓝、自然绿、优雅紫）
- **深色/浅色主题**：完美适配 Obsidian 的深色和浅色主题；非默认配色会自动提亮（暗色主题）或压暗（亮色主题），保证文字对比度达到 WCAG AA

### 2.5 🌐 多语言支持

- **中文/英文**：支持界面语言切换，满足不同用户需求
- **文本本地化**：所有界面文本完整翻译，使用体验一致

## 3 🌟 亮点特色

### 3.1 可配置的生日属性

不再局限于 `birthday` 属性名！你可以使用任何喜欢的属性名：

**方式一：使用默认属性**

```
birthday: 1990-05-20
```

**方式二：自定义为 date_of_birth**

```
date_of_birth: 1990-05-20
```

**方式三：自定义为 DOB**

```
DOB: 1990-05-20
```


**只需在插件设置中配置对应的属性名，即可自动识别！**

### 3.2 无需额外属性，一个字段搞定

只需在笔记 frontmatter 中添加生日属性，所有功能自动生效。

### 3.3 侧边栏与主窗口完美适配

- 拖拽到侧边栏 → 自动切换紧凑模式，节省空间
- 拖拽到主窗口 → 自动切换完整模式，显示更多信息

### 3.4 每日提醒

插件每分钟检查一次，在设定时间（默认 `09:00`）之后的第一次检查发出一条通知，把「今天」和「提前 N 天」的生日合并在一起：

```
今天：张三（36岁）、李四（30岁）
3天后：王五（28岁）
```

- 桌面端走系统通知，移动端或系统通知不可用时退回 Obsidian 应用内提示
- 点击通知直接打开生日面板
- 当天只提醒一次，不会反复打扰
- 命令面板里还有「Birthday Reminder: 检查今日生日提醒」，随时可以看当天会提醒什么。这个命令只弹应用内提示、不占用当天名额，所以上午手动试过之后，9 点的自动提醒照常会来

### 3.5 农历生日

除了公历生日，还可以按农历记录。每年插件会把农历日期换算成对应的公历日期：

```
lunar_birthday: 1990-04-26
```

闰月把 `L` 缀在月份后面，例如 `2023-02L-01`。如果某一年没有这个闰月，会自动按普通月计算，不会漏掉。农历条目在列表里带「农历」徽标，提醒文案里也会出现。

### 3.6 搜索与别名

搜索框同时匹配姓名和别名，输入一部分就能筛出来：

```
birthday: 1990-05-20
aliases: [小李, 阿四]
```

别名支持 YAML 列表，也支持一行逗号分隔（`aliases: 小李, 阿四`）。只在靠别名命中时，条目上会标出「别名：小李」——这样你不会疑惑「这人我没搜这个名字，为什么出现在结果里」。

输入框右侧有 × 按钮，有内容时出现，点击即可清空并保持焦点。

### 3.7 农历精确转换

使用专业 `solarlunar` 库，支持 1900-2100 年农历精确转换，正确处理闰月。

### 3.8 优雅的日历视图

- 月初月末自动补全上月下月日期
- 跨月日期以半透明显示
- 今日日期特殊边框高亮
- 生日格子支持悬停提示

### 3.9 一键跳转笔记

点击任意生日卡片或日历中的生日人名，立即打开对应笔记，无需手动搜索。

### 3.10 性能优化

- 使用 `ResizeObserver` 监听窗口变化，实时调整布局
- 生日数据按月建立索引，日历渲染 O(1) 复杂度
- 每小时自动刷新一次数据
- 编辑笔记正文不会触发列表重绘——只有生日、农历、别名属性真正变化时才刷新

## 5 🚀 快速开始

### 5.1 安装方式

插件现已上架 **Obsidian 社区插件市场**！🎉

#### 方法一：从社区插件市场安装（推荐）
1. 打开 **设置** → **社区插件**
2. 点击 **浏览**，搜索 `Birthday Reminder`
3. 点击 **安装**，然后点击 **启用**

#### 方法二：通过 BRAT 安装
1. 打开 **设置** → **BRAT**（在第三方插件列表中找到）
2. 点击 **Add Beta Plugin** 按钮
3. 在弹出的对话框中输入仓库地址：`https://github.com/ichris007/Obsidian-Birthday-Reminder`
4. 点击 **Add Plugin** – BRAT 会自动下载并安装
5. 进入 **设置** → **社区插件**，找到 **Birthday Reminder** 并启用

#### 方法三：手动安装
1. 从 [Releases](https://github.com/ichris007/Obsidian-Birthday-Reminder/releases) 下载最新版本的 `main.js`、`manifest.json`、`styles.css`
2. 解压到 `.obsidian/plugins/birthday-reminder/`
3. 重启 Obsidian 并启用插件

### 5.2 配置步骤

1. **启用插件**后，点击插件旁边的「设置」图标
2. **设置生日属性名称**（可选）：如果你使用自定义属性名如 `date_of_birth`，在此输入
3. **设置目标文件夹**：指定包含人员笔记的文件夹（如 `07Relations/`）
4. **根据需要调整其他选项**（配色、显示内容、提醒时间等）
5. **在目标文件夹的笔记中添加生日属性**：

插件会读取三个属性，全部可选，按需填写即可：

|属性|用途|示例|
|---|---|---|
|`birthday`|公历生日（属性名可自定义）|`birthday: 1990-05-20`|
|`lunar_birthday`|农历生日，闰月写 `L`|`lunar_birthday: 2023-02L-01`|
|`aliases`|别名，仅用于搜索命中|`aliases: [小李, 阿四]`|

一条完整的笔记头部大概是这样：

```yaml
---
birthday: 1990-05-20
lunar_birthday: 1990-04-26
aliases: [小李, 阿四]
---
```

同一个文件同时写了公历和农历属性时会生成两条记录（同一个人出现两次），按需只填一种即可。

### 5.3 使用方式

- 点击左侧边栏的蛋糕图标 🎂 打开生日提醒面板
- 或使用命令面板（Ctrl/Cmd + P）输入「Birthday Reminder: 显示生日提醒面板」
- 命令面板里的「Birthday Reminder: 检查今日生日提醒」可以随时查看当天会提醒什么，且不影响自动提醒

## 10 💡 常见问题

### 10.1 Q: 我使用的是 `date_of_birth` 属性，能支持吗？

A: 可以！在插件设置中将「生日属性名称」改为 `date_of_birth` 即可。

### 10.2 Q: 能否支持多个不同的属性名同时使用？

A: 目前只支持单一属性名，但你可以选择最常用的那个，其他笔记只需统一修改即可。

### 10.3 Q: 农历日期准确吗？

A: 插件使用专业 `solarlunar` 库，支持 1900-2100 年的精确农历转换，包含闰月处理。

### 10.4 Q: 侧边栏和主窗口的布局会自动切换吗？

A: 是的！插件会自动检测窗口宽度，小于 450px 时切换为紧凑模式，大于等于 450px 时切换为完整模式。

### 10.5 Q: 农历生日怎么记录？

A: 在笔记的 frontmatter 里写 `lunar_birthday: 1990-04-26`，年份填农历年。闰月把 `L` 缀在月份后面：`lunar_birthday: 2023-02L-01`。如果某一年没有这个闰月，插件会自动按普通月计算。想换属性名，改设置里的「农历生日属性」；留空即关闭农历生日。

### 10.6 Q: 每日提醒什么时候发？

A: 每天在设定时间（默认 `09:00`）之后的第一次检查发一条，且只在有内容时发。桌面端用系统通知，移动端用 Notice，点击可直接打开面板。也可以随时手动运行命令「Birthday Reminder: 检查今日生日提醒」。

### 10.7 Q: 能不能用别名搜索？

A: 能。默认读取笔记的 `aliases` 属性，搜索时姓名和别名一起匹配：

```yaml
---
birthday: 1990-05-20
aliases: [小李, 阿四]
---
```

也可以写成一行 `aliases: 小李, 阿四`。只靠别名命中时，条目上会显示「别名：小李」，让你知道它为什么出现在结果里。属性名可在设置 → 数据源 →「别名属性」修改，留空则只按姓名搜索。

### 10.8 Q: 到点了却没收到提醒？

A: 先按顺序排查：

1. 设置里「启用每日提醒」是否打开，以及「提醒时间」是否已经过去（插件每分钟检查一次，到点后最多延迟 60 秒）
2. 当天是否已经提醒过——同一天只发一次；想重测可把插件数据里的 `lastNotifiedDate` 清空
3. **macOS 用户注意**：Electron 的 `Notification.permission` 在 macOS 上恒为 `granted`，插件无法判断「系统设置 → 通知 → Obsidian」里的总开关是否被关闭。如果那个开关是关的，自动提醒会静默失败。请到系统设置里确认 Obsidian 的通知权限，并检查是否开了专注模式

想确认插件本身是否正常，运行命令「Birthday Reminder: 检查今日生日提醒」——它只走应用内提示，一定能看到结果；如果它能显示内容，说明数据没问题，问题在系统通知权限上。
